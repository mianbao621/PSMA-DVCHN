# PSMA-DVCHN

Implementation of **PSMA-DVCHN**, a deep learning framework for small molecule–miRNA association prediction.

PSMA-DVCHN integrates conventional biological features with large language model (LLM)-derived semantic representations, and jointly captures pairwise graph topology and higher-order structural relationships through graph convolutional and hypergraph convolutional networks.

## Overview

PSMA-DVCHN contains the following main components:

- Conventional biological feature representation
- LLM-derived semantic feature representation
- Feature alignment and fusion
- Graph Convolutional Network (GCN)
- Hypergraph Convolutional Network
- Contrastive learning between graph views
- Learnable adaptive feature fusion
- Bilinear decoder for association prediction

The framework is designed to jointly model pairwise association topology and higher-order structural information for small molecule–miRNA association prediction.

## Datasets

Two dataset configurations are provided.

### Dataset 1

- 541 miRNAs
- 831 small molecules
- 664 known small molecule–miRNA associations

### Dataset 2

- 286 miRNAs
- 39 small molecules
- 664 known small molecule–miRNA associations

The association matrix is stored in:

```text
miRNA_SM_adj.txt
```

where:

- `1` represents a known small molecule–miRNA association.
- `0` represents an unconfirmed small molecule–miRNA pair.

For each dataset, two types of features are used:

```text
miRNA_feature.txt
SM_feature.txt
```

contain the conventional biological features, while

```text
miRNA_llm_dataset*.txt
SM_llm_dataset*.txt
```

contain the LLM-derived semantic representations.

The two feature sources are separately aligned and subsequently concatenated to construct the final node representations.

## Model Architecture

PSMA-DVCHN adopts a dual-branch graph representation architecture.

### GCN Branch

The GCN branch models pairwise association topology based on known small molecule–miRNA associations.

### Hypergraph Branch

The hypergraph branch captures higher-order relationships among nodes. The hypergraph is constructed using feature similarity and a K-nearest-neighbor strategy.

### Contrastive Learning

Contrastive learning is introduced to encourage consistent representations between the GCN and hypergraph views.

### Adaptive Fusion

The representations generated by the two branches are combined using a learnable fusion gate:

```text
Z = α · Z_GCN + (1 - α) · Z_Hypergraph
```

where `α` is automatically optimized during training.

### Bilinear Decoder

A bilinear decoder is used to estimate the association score between a small molecule and a miRNA.

| Hypergraph K | 10 |

During the first 100 epochs, the model is optimized using the contrastive learning objective. After the warm-up stage, the association prediction loss and contrastive learning loss are jointly optimized.

## Evaluation Protocol

The model is evaluated using five-fold cross-validation.

For each fold:

1. Known small molecule–miRNA associations are divided into training and test sets.
2. A validation subset is further sampled from the training portion.
3. Negative samples are sampled from unconfirmed small molecule–miRNA pairs.
4. Training negative samples are dynamically generated during training.
5. Validation and test sets use balanced positive and negative samples.
6. Early stopping is performed according to validation AUC.
7. The model corresponding to the best validation AUC is restored for final testing.

The positive-to-negative ratio used in the main experiment is:

```text
1:1
```

- Ablation studies
- Parameter sensitivity analysis
- Robustness experiments
